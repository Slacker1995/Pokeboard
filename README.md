# Pokéboard

A Pokémon board game adventure through Kanto, with local play and direct-host online play for 2–6 trainers.

## Download and play

Open **Releases**, choose **v0.1.0**, and download **Pokeboard-0.1.0-Windows-x64.zip** from **Assets**. Extract the entire ZIP, then open **PokeBoard.exe**. Keep its `.pck` file beside it. Godot is not required.

Use the release download rather than **Code → Download ZIP**, which contains this repository's documentation.

The Windows player edition includes the authored Kanto map, Pokémon, battles, badges, items, trainer cards, round events, legendary encounters and Safari Zone. It has **no Dev menu, Debug menu, editor screens, F3 cheats or Test Battle launcher**.

## Playing together

For one computer, choose **New Game**. For separate computers, choose **Online**: one trainer hosts, the others join using the host's address and port. Each participant controls their own turns. Everyone watches the active trainer's adventure. See [Online play](ONLINE_PLAY.md).

The host can save, resume and reconnect trainers. Master, Music and Sound Effects volumes are local to each computer. Across different networks, direct hosting can require UDP port forwarding (default port **28961**).

## Access

This repository is public. Anyone can download a release without an invitation. This repository distributes the player build and instructions; the authoring project and personal saved games are not included.
